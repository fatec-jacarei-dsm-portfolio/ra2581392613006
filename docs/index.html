Projetos Desenvolvidos (ABP)

1º Semestre (1DSM) - Projeto "Scrum do Zero"

Descrição: Desenvolvimento de um portal web para certificação interna em metodologias ágeis, com foco em Scrum, pela equipe Team Zero. A aplicação permite que usuários se cadastrem, realizem avaliações organizadas por níveis de dificuldade e acompanhem sua evolução para a emissão de certificados.

Tecnologias utilizadas: HTML5, CSS3, JavaScript (Front-end), Node.js e PostgreSQL (Back-end e Banco de Dados), além de Figma para o Design.

Minha contribuição: Colaboração ativa no desenvolvimento do sistema junto à equipe Team Zero, aplicando os conceitos de metodologia ágil e desenvolvimento full-stack.
